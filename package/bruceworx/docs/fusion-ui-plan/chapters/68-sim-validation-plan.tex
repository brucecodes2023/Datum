\subsection{BW-SIM-05 plan: validation against open data (31 Oct 2026)}\label{sec:sim-validation-plan}
%======================================================================

You asked for the simulation to be validated against open-source data. So far every check compares the solver
with a closed-form answer: the cantilever, the Euler column, the fin and lumped cooling, and for CFD the pipe,
the sphere correlation and momentum theory. Those checks show the equations are solved right
(\emph{verification}). They do not show that the model behaves like the real part (\emph{validation}), and
they cover only simple shapes. This plan adds three tiers:
\begin{description}[nosep,font=\normalfont\bfseries]
  \item[V --- verification.] Closed-form checks, as now. They run on every build.
  \item[B --- benchmarks.] Published reference solutions for 3D solids from other codes and standards bodies:
        NAFEMS, and the Code\_Aster validation manuals. These test the mesh, the element and the
        post-processing on shapes where the answer is not obvious.
  \item[E --- experiments.] Measured data: wind-tunnel airfoil data for CFD, printed-specimen tests for
        materials, and (question V5) tests on your own parts.
\end{description}
A Sonnet research agent searched the open sources. Each value below was read in the source unless the
\emph{Status} column says otherwise. No value was taken from memory.

\paragraph{Sources and licences.}
\begin{itemize}[nosep]
  \item \textbf{Code\_Aster validation manuals (V-docs).} GNU Free Documentation Licence, stated in each PDF.
        Their values can be stored with a citation. The official URLs now return 404; the copies used are from a
        university mirror (v14.4).
  \item \textbf{NAFEMS benchmarks.} The documents are paid. The reference values are reproduced in open vendor
        verification manuals (ANSYS VMC5, Altair) and online pages. We store only the numbers with a citation.
  \item \textbf{NASA Turbulence Modeling Resource (TMR)} and the \textbf{UIUC propeller database.} They state no
        reuse terms, so their data files are downloaded at test time and cached, not stored in the repo.
  \item \textbf{CalculiX's own test suite.} Its reference files are CalculiX's own output: regression data, not
        validation. It is mostly beams, shells and 2D, so it is not used here.
\end{itemize}

The check of B-TH1 is
$T(r)=-\frac{\dot q r^2}{6k}+\frac{A}{r}+B$ with $T(1)=T(2)=20$, which gives $A=-100$ and $B=136.67$, and so
$T(1.5)=32.5\,^\circ$C. This agrees with the manual.

\paragraph{Gaps the search could not fill.} No open numeric reference was verified for:
\begin{itemize}[nosep]
  \item one-way thermal stress;
  \item nonlinear buckling;
  \item prestressed or constrained modal (Code\_Aster SSLV104/105 are candidates, but the values were not
        extracted);
  \item open per-specimen data from printed tests;
  \item open modal-test data for beams or plates;
  \item tabulated sphere and cylinder drag;
  \item heated-block forced convection (Young and Vafai is behind a paywall).
\end{itemize}
The cheap fix is more closed forms, which is question V2:
\begin{itemize}[nosep]
  \item a thick cylinder with a radial temperature difference (Timoshenko's closed form) for thermal stress;
  \item a beam under axial tension, whose frequencies rise as $\omega_n^2=\omega_{n,0}^2(1+PL^2/(n^2\pi^2EI))$
        for simple supports, for prestressed modal;
  \item a column with an initial bow (Southwell plot) for nonlinear buckling.
\end{itemize}
The real fix for the drone is measured data from your own parts (V5).

\subsubsection*{How it runs}

\begin{itemize}[nosep]
  \item Each case is an entry in \file{tests/validation/cases.json} with the geometry script, the loads, the reference
        values, the tolerance, the source and the licence. A Python script builds the model, so nothing binary
        is stored.
  \item \textbf{Fast set} (V and B on coarse meshes, a few minutes in all): runs with the other tests on every build.
        \textbf{Slow set} (finer meshes, the NACA~0012, the Ahmed body): run on demand.
  \item \textbf{Validation report.} The command \emph{Simulation~$\rightarrow$ Validation} runs a set and writes a
        \LaTeX{} report: one row per case with the reference, the result, the error and a pass mark, plus the
        mesh-convergence plot for each benchmark. Re-running it after a CalculiX or OpenFOAM update shows at once
        whether anything moved.
\end{itemize}
