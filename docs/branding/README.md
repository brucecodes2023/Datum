# Heuretes FreeCAD icon

The mark is the Heuretes app icon: a warm off-white tile, a black ring, a tick up, and a tick to the right. The FreeCAD build adds a blue drawing-sheet corner so the two apps are not the same icon.

**Chosen: option A** (blue corner). B is a blue ring in the hole. C is a blue end-cap on the right tick.
